VIDEO DOWNLOADER
================
Download YouTube videos, Shorts and music (and videos from most other sites)
to your Windows PC or your phone. Free, no ads, no account.

INSTALL
  1. Right-click the ZIP file > "Extract All..." > "Extract"
     (Setup does not work from inside the ZIP).
  2. In the folder that opens, double-click  Setup.cmd  (it may show as just "Setup").
     If Windows says "Windows protected your PC": click "More info" > "Run anyway".
  3. Follow the guide that opens to add the Download button to YouTube (2 minutes).

UPDATE (keeps your settings, queue and history)
  Press Windows key + R, type  video-downloader update  and press Enter.
  Or: Start menu > "Update Video Downloader".
  It gets the newest Video Downloader and updates yt-dlp and Deno. The same
  command works for every future version. Setup.cmd from a newer download
  also updates an existing installation.

USE
  - Click the red Download button under any YouTube video, or
  - open "Video Downloader" from the Start menu and paste a link.

HELP
  Click Help in the Video Downloader window: the guide, "Check for updates now"
  (yt-dlp and Deno), "Check my connection" and the project page with the full README.
  Type  video-downloader help  in the Run box for the other commands.

UNINSTALL
  Settings > Apps > Installed apps > Video Downloader > Uninstall
  (or type  video-downloader uninstall  in the Run box).

NEEDS
  Windows 10 or 11. Setup installs the free helper programs yt-dlp, FFmpeg and Deno
  with Windows' own package manager (winget) if you don't have them.

Only download videos you have the right to save. Respect copyright and YouTube's Terms.
